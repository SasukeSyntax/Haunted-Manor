# 🏚️ The Haunted Manor

A spooky, text-based interactive choose-your-own-adventure game built entirely with vanilla web technologies. Step inside a mysterious abandoned house, avoid dangerous spirits, and figure out how to break the curse before you get trapped forever.

Live Demo: https://sasukesyntax.github.io/Haunted-Manor/

---

## 🛠️ Built With

* **HTML5:** Semantic page layouts and multiple branching paths across dedicated room files.
* **CSS3:** Custom responsive layout, smooth hover transitions, custom Google Fonts (`Nosifer`, `Share Tech Mono`, `IM Fell English SC`), and atmospheric color palettes tailored to each room.
* **JavaScript:** Lightweight vanilla JS handling the EMF night-vision mode, interactive 3D Bestiary flip-card modal, dynamic text reveals, and the 4-digit basement keypad verification.

---

## 🕹️ What It Does

* **Branching Navigation:** You start in the Grand Foyer and make decisions that take you deeper into the house—from the Dusty Attic and Candlelit Library to the Flooded Conservatory and locked Basement.
* **Ghost Hunter's Bestiary:** A popup book feature featuring collectible 3D flip cards with threat levels, lore, and weaknesses for spirits like the Poltergeist, Banshee, and Archivist.
* **EMF Vision:** A toggleable night-vision mode that shifts the screen into a radioactive green theme, uncovering invisible clues and secret digits hidden throughout the house.
* **Puzzle Solving & Keypad Lock:** Find clues scattered across rooms and Bestiary entries to crack the 4-digit code (`3142`) guarding the basement server room.
* **Multiple Endings:** Surviving requires using the correct ghost weaknesses from the Bestiary; wrong choices lead to a game-over screen, while solving the mystery shuts down the curse for good.

---

## 💡 Why I Made It

Instead of just building a static landing page, I wanted to push myself to see how much immersion and interactivity I could create using mostly HTML and CSS, backed by simple, beginner-friendly JavaScript. It helped me practice multi-page file routing, CSS 3D card flips, responsive flexbox/grid containers, and writing my own lore and game mechanics from scratch.
